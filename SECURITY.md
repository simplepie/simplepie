Security Policy
===============

Supported versions
------------------

Security fixes are made for the latest SimplePie release. Please check that the
problem still exists in the latest release before reporting it.

Reporting a vulnerability
-------------------------

Please don't open a public issue or pull request for a security problem.

Report it privately through GitHub's [private vulnerability reporting][report]
on this repository. Include the affected version, a description of the problem
and, if you can, a minimal feed or code sample that reproduces it.

[report]: https://github.com/simplepie/simplepie/security/advisories/new
